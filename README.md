# Comandadigitalprint

Aplicativo Expo para montar, salvar e imprimir comandas Android.

## Executar

```bash
npm install
npm run start
```

O roteiro de teste, gravacao e apresentacao esta em [PLANO-TESTE-APRESENTACAO.md](PLANO-TESTE-APRESENTACAO.md).

Para imprimir pelo sistema Android, use um development build com `expo-print`. Bluetooth, Wi-Fi/rede e USB/OTG permanecem configuraveis e precisam do modulo nativo e do equipamento real para validacao direta.
