# Bandeiras dos idiomas

Brasil: português brasileiro; Estados Unidos: inglês americano; Espanha: espanhol.

Os PNGs do aplicativo e os SVGs de `server/cloudflare/language-flags.mjs` derivam de [flag-icons v7.5.0](https://github.com/lipis/flag-icons/tree/v7.5.0/flags/4x3), distribuído sob a licença MIT em `LICENSE.txt`. Os arquivos são incluídos no aplicativo e no HTML dos painéis; não dependem de downloads ou suporte a emojis.

As bandeiras são decorativas. Os botões mantêm o nome do idioma e a indicação de seleção para leitores de tela.
