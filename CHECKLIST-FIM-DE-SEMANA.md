# Checklists detalhados para o fim de semana

Registro consolidado em 22/10/2026. Cada demanda está em um arquivo separado, com requisitos, tarefas de conferência/execução, decisões pendentes e critérios de verificação. Nada foi marcado como concluído apenas por ter sido registrado.

O foco da retomada é desenhar/revisar o fluxo de Caixa. O cardápio online é uma frente separada; checkout com pagamento e pedidos programados permanecem identificados como etapas posteriores. Não há promessa de realizar todas as frentes no mesmo fim de semana.

## Como acompanhar

- Abrir cada documento e usar as caixas `[ ]` / `[x]` para registrar o andamento real.
- Conferir primeiro o que já existe no sistema e complementar o que faltar; item não marcado não significa que sua função inexiste.
- Resolver os pontos em “Decisões pendentes” antes de implementar a regra correspondente.
- Registrar decisões novas e continuar adicionando as demandas que o proprietário lembrar.
- Este pacote não inicia implementação, alteração de dados, publicação ou compilação de APK.
